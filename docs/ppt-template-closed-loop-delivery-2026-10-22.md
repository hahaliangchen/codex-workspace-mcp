# 模板闭环实施与验收记录

日期：2026-10-22。对应 [实施计划](ppt-template-generation-closed-loop-plan-2026-10-22.md)。实际模型恢复验收仍在进行，不能将本文的单元测试或转换测试视为全部产品验收通过。

## 已实现

- 保持 PPTX ⇄ 内存 JSON ⇄ HTML；AI 内容设计只走 HTML，文稿只持久化 PPTX。
- 统一固定、可变内容、参考素材三种用途。用途和页面说明写入版本化 PPTX 轻量扩展，普通生成不能修改用途；模板 AI 标注需要宿主显示并确认具体变化。
- 固定 Logo 的移动、删除、改图、改样式、通过 CSS 隐藏和新增内容覆盖会被拒绝；原生复制、删除、撤销重做会同步维护标注身份。
- 支持复制模板页并继承素材、母版与用途；不要求四种角色，也不删除未分类页。
- 模板制作保留未保存页面说明和用途草稿，发布及试生成前阻止遗漏未保存内容。
- 试生成创建独立普通项目，记录来源草稿版本/哈希，复用正常编辑器和模型任务；刷新不重复提交。
- 发布版本与对应说明保持一致，公开目录返回版本/哈希；Agent 将 UI 选择固定到会话及子任务，模型不能换掉版本。
- 生成与检查指引统一；完整保留 Anthropic 审美与视觉检查原文，不新增自动缩字、自动填槽或固定卡片排版。
- 已补只读属性错误的具体节点/属性/前后值，以及修复后继续的指引。
- 来源哈希格式错误与真实版本过期分别诊断，返回期望值/提交值；单页设计读取保留当前页完整内容，省去重复的全稿语义概览。

- LibreOffice 26.2.6.3 另存 PPTX 会删除用途扩展，页面说明/对象用途丢失，部分固定矩形被其改写为空文本形状后回到默认可变；重新导入必须审视用途。PowerPoint、WPS 未验证。本应用自身保存重开保留标注。

- 字体差异、复杂 OOXML 与保守遮挡检查仍需结合实际渲染审视；不保证任意模板或所有办公软件无损往返。
