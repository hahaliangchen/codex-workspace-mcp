## 已实现的主要改动

1. **Agent 通用任务定义**：主目标、任务约束、完成条件和来源独立落库；不是 PPT 专属，不永久注入所有聊天原文。生效任务和已确认大纲在可压缩工作窗口之外注入；原始对话保留引用。
2. **显式确认**：模型的 `update_task_definition` 只能创建待确认提案。用户点击任务卡片确认指定版本后才生效；拒绝、重复确认、过期确认有确定性处理。普通聊天及“继续”不会直接覆盖生效目标。Agent 和 PPT 均有确认界面。
3. **PPT 生产流程**：完整逐页大纲保存并通过独立按钮确认；生成按大纲进行。页面容器、正文写入和视觉验收分开记录；正式 AI 导出要求当前版本全部计划页验收通过。用户可主动下载草稿。
4. **模板与设计层（本次一并提交此前累计改动）**：PPTX/OOXML ⇄ 内存 JSON ⇄ HTML/CSS；AI 从 HTML 操作，编辑器保存/导出 PPTX。模板用途区分固定、可变、参考；固定 Logo 和品牌元素受保护；模板制作有草稿、说明、标注确认、版本发布和独立试生成。保留 Anthropic 审美与视觉检查参考，补回 ppt-master 的策划、大纲、素材、执行和验收流程。
