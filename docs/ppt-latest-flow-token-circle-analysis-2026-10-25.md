## 红色圆点

第三页的实际提交 HTML（seq 258）中，三个圆点均为 `width:24px;height:24px;border-radius:12px;background-color:#e60012`，宽高相同且半径是边长一半，HTML 描述正确。

引擎链路：

- `src/design/measure-dom.ts:83` 将其测量为半径 12px。
- `src/design/export-core.ts:213` 将半径映射为 `roundRect` 的 `adj=50000`。这一圆角矩形预设在正方形且 50% 半径时可以表达圆形，不能仅凭预设名称认定 PPT 文件几何有错。
- `src/pptx-parser.ts:1319` 读取该调整值为 0.5。
- `rust-engine/src/shape_geometry/basic.rs:15` 转入 `rounded_rect`。
- `rust-engine/src/shape_geometry/helpers.rs:71` 每个角使用一个 `quadratic_curve_to`，控制点直接取外侧方角；这是近似曲线，不是圆弧。半径达到边长一半时，仍呈略偏方的轮廓，符合截图现象。理想化 45 度中点的半径约为圆半径的 1.06066 倍，12px 半径时约偏出 0.73px。

应在引擎圆角绘制路径中使用真正圆弧（如 Canvas arcTo/ellipse），保留当前 CSS 语义。不是要求 AI 换宽高、改模板、改审美或增加视觉模型检查。当前分析没有下载最终 workId 171 文件逐项核验 OOXML，因此不把画布显示问题扩大断言为 PowerPoint 本身也必然不圆。
