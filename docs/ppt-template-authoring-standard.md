# PPT 模板制作与转换标准

适用日期：2026-10-22。供整理、转换和发布模板的制作人员使用。本文按当前本地实现编写；部署环境须同时更新前端、后端工具声明与 Agent skill。本文不表示真实模型已完成整套发布与生成验收。

## 1. 模板交付什么

交付一份 **16:9 PPTX 初稿、必要的用途标注和简短设计说明**。设计工作视图固定为 1280×720。模板可以只有一页品牌背景，也可以有多页可参考的版式，不要求集齐封面、目录、正文、结束页。

AI 会读取原稿的 HTML 结构、示例内容、样式和素材，决定复用、轻改或重新设计。布局是参考，不是固定填槽骨架。不要为了适配模板强制等距、统一卡片数量、设置一批必填关键字，或要求内容必须塞进原来的文本框。

文稿只保存 PPTX。JSON 和 HTML 是转换时的内存工作表示，不另存一份设计 JSON 或 HTML 作为第二个文稿。名称、标签、整体设计说明和缩略图仍由现有模板业务管理。

## 2. 上传后先检查品牌和素材

从“模板制作”上传 PPTX，或复制已有模板到自己的草稿。先逐页看实际画面，再整理对象用途。

**Logo、品牌文字、品牌组合标识和固定背景图应当保留。** 未标注的原有图片、复杂素材默认固定，不能因为它以 PNG 显示就当成可替换图片。只有制作人明确指定为可变或参考，AI 才有相应权限。单独的“封面”“正文”等页面角色标注不会解除图片或背景的保护。

制作时仍须核对保护结果：程序不能可靠识别所有未命名的品牌文字。选中品牌文字及组合对象，检查其当前用途；遗漏时在属性面板设为固定。不要通过删除锁定属性或把品牌改名为普通内容来规避保护。

| 对象用途 | AI 可以做什么 | 制作时怎么选 |
|---|---|---|
| 固定 | 保持内容、位置、大小、比例和外观，不能删除或被新内容遮挡 | Logo、固定页眉、品牌文字、固定装饰 |
| 可变内容 | 修改文字、替换图片，按新内容调整布局 | 标题、正文、作者、日期、明确的配图占位 |
| 参考素材 | 理解示例的视觉或表达意图，按新主题重做、替换或删除 | 总结示例图、流程示例图、示意插画 |

说明只写必要的一句话，例如“根据本页正文重新组织因果关系图”。图标、照片和流程图究竟固定还是可变，由用途决定，不由文件类型决定。

固定组的保护覆盖子对象。参考组可以整体重做，但其中仍有固定或技术锁定成员时，不能顺带删除它们。涉及 Logo 的混合组应先整理清楚成员用途。

## 3. 整理内容与页面说明

保持真实、可读的示例文字，让 AI 看懂层级和表达方式。新制作的模板不要求写 `{{TITLE}}` 一类关键字；原稿已有关键字时，可以换成真实示例，再设为可变内容。不要把品牌名称当作待替换的示例文字。

页面用途、版式名和适用说明都是可选项。例如“封面 / 红白品牌封面”“正文 / 双栏对比”。留空合法，发布时不会因为未分类而删除页面。页面用途只是帮助挑选参考页，不决定输出必须有几页。

整体设计说明建议写清楚：

- 主要颜色、字体和视觉风格，以及需要保持的品牌元素。
- 现有版式适合什么内容，哪些区域可以自由调整。
- 哪些图是主题参考，使用时必须更新其内容。

描述不能改变对象的结构化权限。例如对象仍是固定时，只在说明里写“可以替换”不会将它解锁；应同时在属性面板明确改变用途。

## 4. 让 AI 帮忙制作模板

手动编辑和 AI 编辑都使用同一份文稿。AI 的所有内容与设计修改统一操作 HTML，包括改一个字、替换图片和重做整页；制作人手动拖动、改字、撤销或重做后，宿主会使旧 HTML 失效并刷新投影。

AI 提出用途变化时，界面会列出具体对象及修改前后值。**把固定对象改为可变或参考，必须由制作人确认这一次具体变更。** 确认期间文稿版本变化，旧确认就失效。普通 PPT 生成任务不能自行改变这些权限。

AI 可以保留布局，也可以根据内容调整布局。不能为了消除问题自动缩字、把文字隐藏到框外，或声称“没有重叠”就表示设计已完成。转换器不支持的复杂效果应作为独立素材处理。

## 5. 试生成、发布与正式选用

1. **先保存用途和当前草稿。** 属性面板仍有未保存改动时，先保存或取消，再进入后续操作。处理检查中的错误，并查看字体替换提示。
2. **点击“试生成”。** 填主题和本次目标页数。当前输入允许 1–100 页；默认的 5 页只是快速测试值，不是正式生成的固定页数或质量承诺。
3. **在独立副本上检查。** 系统复制当前已保存版本，记录来源版本和哈希，进入正式 PPT 编辑页执行生成、保存和检查。来源草稿保留，试生成结果可以继续编辑。
4. **修正模板后再试。** 试生成里的局部修复不会自动回写来源模板；需要成为通用规则的修改，应回到模板草稿调整用途、示例或说明，再创建新的试生成副本。
5. **保存为我的模板。** 填写名称、设计说明等信息并发布。发布使用当前保存版本、页面顺序、说明和缩略图。单页和未分类页都可以保留。
6. **正式新建 PPT 时选用。** AI 读取所选模板，复制合适的参考页，再通过 HTML 设计。不要让它重画品牌 Logo，或重新初始化已有的生成稿件来处理某一页的失败。

首次转换一个模板时，建议先试少量页面，再试 20 页，检查复制与长文稿中的重复布局、旧内容残留和逐页保存。模型必须使用 Agent 授权的配置；模板制作与 PPT 插件不另外配置一套密钥或模型权限。

## 6. 验收一份模板

验收查看的是 **编辑器实际 PPT 渲染及导出后重新打开的 PPTX**，不能只看 HTML 预览，也不能只读结构检查结果。

| 检查点 | 合格要求 |
|---|---|
| 品牌 | Logo 和品牌文字的内容、位置、比例、颜色保持，新增内容没有遮挡 |
| 文字 | 字完整，换行合理，字号与行距可读，没有裁切、重叠和异常缺字 |
| 图片与图标 | 资源能显示；没有用缺字方框、单个汉字或失效图标字体冒充图标 |
| 示例清理 | 没有旧主题、待填关键字、未更新的作者日期；参考图表达新内容 |
| 设计 | 有适合内容的层级和构图；空模板能够自由设计，有布局的模板可以复用或调整 |
| 长文稿 | 每一页都保存并检查，不能只检查前几页；失败后能从现有稿件继续 |
| 手动编辑 | 手动改字或移动可变对象后，AI 再改另一处不会覆盖手工结果 |
| 往返 | 保存、关闭、重开后用途仍在；导出再导入没有丢素材或组关系 |

视觉或模型调用失败时保留“待检查”状态，不能把结构检查通过当作视觉检查通过。参考用途只表示允许重做，不代表程序已验证 AI 确实更新了图中的含义；制作人要看实际结果。

## 7. 联通品牌封面的整理示例

对于右上角带“中国联通 / 联通元景”标识的封面：

- 右上角品牌标识保持固定，不改变位置、比例、颜色，也不允许正文覆盖。
- 标题、副标题、作者、日期设为可变内容，保留原稿有用的配色和层级。
- 左侧固定装饰按模板意图保留；若它属于可调整的内容布局，由制作人明确选择用途。
- 页面用途可以写“封面”，也可以留空；不要把标识命名为“封面”当成解锁手段。
- 正文页的总结示例图明确设为参考，并说明“根据正文重新组织关系”。不能让 AI 把一张带旧主题的总结图直接当新稿成品。

现有引擎回归使用了这类真实联通模板的副本，覆盖普通图片 Logo 保护、语义保存重开、20 页复制和原生编辑。这个示例是制作规则，不能据此推断任意模板或真实模型生成都已经通过验收。

可直接参考 [单页品牌模板 PPTX](examples/ppt-template-closed-loop/unicom-brand-template.pptx) 和 [转换验收说明](examples/ppt-template-closed-loop/README.md)。

## 8. 当前边界

- **简单对象和复杂素材分开处理。** 可支持的文字、基础形状和组结构进入 HTML；复杂对象以独立预览资产显示，未修改时保留原始素材或原 OOXML，不把整页做成截图。明确可替换的复杂素材可整体替换，不能承诺编辑其内部 SmartArt 或特殊效果。
- **PNG 预览不等于 PNG 降级保存。** 原对象未修改，继续保留原来源。技术上不可预览或不可转换的对象，不会因为改成“可变”就自动获得内部编辑能力。
- **纯色背景有区别。** 直接的 PPT 纯色页面背景 `p:bg` 当前可以调整，没有单独的固定/可变开关；独立背景图片或形状按对象用途保护。不能声称所有背景都已锁定。
- **整页位图内部的 Logo 无法自动单独保护。** 若 Logo 与示例内容烘焙在同一张大图中，先拆成独立品牌资产和内容资产。原图默认固定；程序不能凭整页预览准确找出图内所有品牌区域。
- **遮挡检查不是逐像素识别。** 透明文字按浏览器实测的可见字形区域检查；有背景/边框的文本框、图片等按完整对象区域检查。整页背景不视为“全页禁止放内容”。最终画面仍须人工或视觉模型查看。
- **字体需实看。** 缺少原字体时可能使用替代字体，不能承诺跨电脑换行完全一致。至少放大检查文字密集页，并在交付环境检查导出文件。
- **本应用保存重开保留用途，外部软件另存不作保证。** 已实际验证本应用的保存、关闭和重开会保留用途标注。LibreOffice 26.2.6.3 使用 `Impress MS PowerPoint 2007 XML` 另存 PPTX 时，会移除本模板的自定义扩展：页面用途、版式名、说明及对象标注丢失；本次样例中四个固定矩形装饰重导入后变为默认可变内容。文件仍能打开，不代表用途仍在。重新上传外部软件另存的文件，须核对并重新设置用途后再交给 AI。PowerPoint 与 WPS 尚未验证，不能推断它们的行为。

## 9. 实施者维护契约

制作人员无需手写以下字段。前端表单和 AI 都通过宿主接口修改同一套语义：

| 层级 | 字段或方法 | 规则 |
|---|---|---|
| HTML 对象 | `data-purpose`、`data-note` | 用途为 `fixed`、`content`、`reference`；只有模板制作的具体授权允许写回 |
| HTML 页面 | `data-page-role`、`data-layout-name`、`data-page-note` | 可选；明确清空页面用途不能被旧标注重新填回 |
| HTML 身份与权限 | `data-id`、`data-kind`、`data-bind`、`data-locked`、版本及来源哈希 | 宿主管理，不能靠改属性取得权限 |
| 人工表单 | `DesignBridge.updateTemplateSemantics(page, edits)` | 使用同一 HTML 转换路径；不暴露为 AI 工具 |
| AI 编辑 | `get_design` → `apply_html` | 对照宿主原始 HTML 按差异合并，未改节点保留 |
| 页面管理 | `manage_design_pages` / `duplicateSlide` | 复制继承素材和规则，副本使用独立身份；操作后重读版本 |
| PPTX 存储 | slide `p:extLst` 中的版本化轻量记录 | 只记录页面语义、物理形状 ID 与对象用途，不存几何副本或完整设计 JSON |

权限确认绑定文稿来源哈希、版本、页面 ID 和确切的前后变化。原生复制对象会映射用途 ID，删除会清理对应记录，撤销/重做后的保存应保持一致。修改规范、工具声明或存储字段时，需要同步验证前端、后端和 skill；不能只改提示词。
