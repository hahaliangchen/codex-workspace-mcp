# 模板用途与保护

模板是 HTML 设计初稿，可以是一页品牌空模板，也可以提供多页版式。页面用途、版式与说明帮助选择，不强制四类页面、不限制输出页数、不按固定骨架填槽。

## 读取与默认保护

从 get_design 取得当前页面 HTML、模式、版本、来源和实际资产。原有 Logo、品牌文字、背景及固定装饰保留。未标注的原有图片/复杂素材默认固定；只有明确可变占位和参考素材可以替换。PNG 表示只是预览，不代表可以重画或覆盖它。

- data-purpose="fixed"：内容、几何、比例和外观保持不变，不得通过新内容覆盖、父组/CSS/图层操作绕过。
- data-purpose="content"：可变内容；按请求改字、替图、复用或调整布局。
- data-purpose="reference"：示例素材；理解其表达意图，为新主题重做，不照搬旧主题。
- data-note：对象的用途说明。没有明确用途的品牌元素不能由模型猜成可变。
- body 的 data-page-role、data-layout-name、data-page-note：可选的页面用途、版式名和说明。

已有 data-id、data-kind、data-bind、data-locked、来源哈希和版本受宿主管理，不能以更改这些属性取得权限。

## 模板制作

先看实际页面，建议哪些保留、哪些可变、哪些作为参考。不要要求所有对象填写参数，也不要把目录数量或等距排列变成发布门槛。保留真实示例文字；不新增 {{TOKEN}} 占位。

在模板制作模式中，修改宿主允许的用途属性及 HTML 内容后 apply_html。用途变化由宿主比较并交制作人确认具体对象和变更；在得到执行结果前不要宣称已标注。旧确认不能用于新版本，也不能在生成任务里改变权限。直接 HTML 修改不能绕过转换器不支持某些原生对象的限制。

普通生成模式只使用既有用途，不能把固定对象标为可变。品牌空模板保留品牌区，其余区域自由设计。必要时通过 manage_design_pages 的 duplicateSlide 复制参考页，继承素材与保护，再读取新页面 HTML；不要用空白页重画 Logo。复制、删除、排序后重读版本和页面列表。

## 保存与检查

语义随 PPTX 保存；不另存设计 JSON/HTML。模板整体设计说明继续使用现有 design_spec.md。描述不能覆盖结构化保护规则。

试生成由模板制作界面在独立文稿上启动，使用正式生成流程，不能 use_template 覆盖正在编辑的草稿。完成后检查真实渲染：品牌未改未遮挡、文字完整、参考图符合新主题、没有占位残留。结构检查不能替代视觉检查。手动修改、撤销重做后必须读取新 HTML。

## 当前转换边界

独立背景图片和形状按对象用途保护；直接的 PPT 纯色背景 `p:bg` 当前可调整，尚无独立用途开关。若 Logo 与示例内容烘焙在同一张整页位图中，应由制作人拆成独立品牌资产；不得依赖自动识别图内的品牌区域。原素材的固定规则仍须遵守，最终实际 PPT 渲染需要检查。
